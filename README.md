# 鯊魚狂歡 Shark Feast

畢業專題網頁遊戲。1930 年代橡皮管卡通風的海洋消除老虎機，由鯊魚大哥主持。**展示用，遊戲裡的錢全是遊戲幣，不涉及真實金錢。**

## ▶ 線上遊玩

**<https://jason876543211-sys.github.io/shark-feast/>**（用 Chrome 或 Edge 開啟；第一次點一下畫面才會有聲音）

## 怎麼玩

- 按大圓形按鈕（或空白鍵）轉動，「＋／－」調整押注，T 鍵切換快速模式，M 鍵切換聲音。
- 盤面上 5 個以上相同符號相連就得獎、消除並掉落新符號，可以連鎖；得獎的位置會變成金色格。
- 漁網撒出後，金色格會變成生魚片（鯛魚、鮪魚、鮭魚，越高級越值錢）、筷子或盤子：筷子把周圍的生魚片加倍，盤子把生魚片收走並留在桌上，之後的筷子也能把盤子加倍。
- 3 個以上瓶中信進入免費遊戲「鯊魚大哥請客」12 轉，每場保底一個漁網。
